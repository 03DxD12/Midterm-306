# ITST 306 UX/UI Flashcards

A clean, mobile-friendly flashcard reviewer for ITST 306 UX/UI and Cross Platform Applications.

## Features

- 109 multiple-choice reviewer cards
- Topic filter and review-only mode
- Reveal answer button
- Fullscreen study mode
- Download button for saving a copy of the page
- Shuffle, next, previous, known, and review controls
- Smooth card flip animation and responsive mobile layout

## How to Use

Open `ITST_306_UXUI_Flashcards.html` in a browser. Choose an answer, reveal the explanation, then mark the card as known or for review.

Keyboard shortcuts:

- `Left Arrow` and `Right Arrow` move between cards
- `R` shuffles the deck
- `F` toggles fullscreen
